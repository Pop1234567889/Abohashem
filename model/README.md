# نموذج التكاليف والتسعير — ABOHASHEM (يونيه 2026)

نموذج محاسبة تكاليف وتسعير كامل، مبني آليًا من بيانات المصنع الفعلية، ومطابَق
لقائمة دخل يونيه 2026 إلى القرش.

## المخرجات
| الملف | الوصف |
|---|---|
| `../ABOHASHEM_Costing_Pricing_Model_June2026.xlsx` | المصنّف النهائي (11 شيت): ملخص تنفيذي، جودة بيانات، تكلفة معيارية، تكلفة فعلية وانحرافات، توزيع مصروفات، ربحية، مبيعات ABC، قائمة الأسعار، قواعد التسعير، منهجية، إعدادات. |

| `costing_pricing_model.py` | محرك النموذج (منطق الاحتساب + محرك التسعير + الإعدادات). |
| `build_workbook.py` | مولّد المصنّف Excel المنسّق. |
| `model_rows.json` | مخرجات لكل SKU (للمراجعة/التكامل). |


## مصادر البيانات (داخل المستودع)
- `قائمة دخل تفصيلى شهر ٦ سنة ٢٠٢٦.pdf` — قائمة الدخل (مطابقة).
- `فواتير_المبيعات_يونيو_2026.md` — 311 فاتورة بيع (كميات/قيم/أسعار).
- `ABOHASHEM_...يونيه2026.xlsx` — وصفات التصنيع بأحدث متوسط تكلفة مرجّح (WAC).
- `تصنيف الاصناف كبراند.pdf` — تصنيف الأصناف حسب العلامة التجارية.

## الإعدادات القابلة للتبديل (`CONFIG` في `costing_pricing_model.py`)
- `expense_allocation_base` — أساس توزيع المصروفات (الافتراضي: مساهمة مجمل الربح؛ يدعم 8 أسس).
- `pricing_strategy` — استراتيجية التسعير: `cost_plus` / `target_gross_margin` /
  `target_net_margin` / `contribution_optimization` / `competitive` / `hybrid` (الافتراضي).
- `target_net_margin` — الهامش المستهدف لكل علامة تجارية.
- `volume_margin_delta` — تعديل الهامش حسب فئة ABC (حجم المبيعات).
- `max_price_increase` / `min_price_decrease` / `round_to` — حدود وتقريب السعر.
- `waste_allowance_pct` / `quality_reserve_pct` — سماح الهدر واحتياطي الجودة.

بعد أي تعديل، أعد تشغيل السكربتين؛ تُعاد كل الحسابات مع الحفاظ على مطابقة القائمة.

## منهجية التكلفة (مختصر)
- **تكلفة المبيعات (2,039,933) = خامات مباشرة + تعبئة** مستهلكة.
- **مجمّع التحويل (544,605)** = أعباء صناعية غير مباشرة تُحمَّل بمعدل كجم.
- **المصروفات التشغيلية (738,392)** = بيع + إدارة + تمويل تُوزَّع لاحتساب صافي الربح.
- المطابقة: `3,741,772 − 2,039,933 − 544,605 − 738,392 = 418,842` = صافي الربح المُعلن.
