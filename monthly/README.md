# ملفات الشهر — قائمة الاستلام

كل شهر مجلد باسمه `monthly/YYYY-MM/` وبأسماء ملفات ثابتة لا تتغير من شهر لشهر، فيحتسب
`model/wac.py` أى شهر دون نسخ سكربت أو تعديله.

| الملف | مطلوب؟ | المحتوى |
|---|---|---|
| `month.json` | مطلوب | استثناءات الشهر (انظر أدناه) |
| `purchases.pdf` | مطلوب | تقرير المشتريات التفصيلى للشهر من البرنامج (كل الأسطر + الإجمالى المطبوع) |
| `stock_count.xlsx` | مطلوب | الجرد الفعلى آخر الشهر: خامات (المواقع B–F، الإجمالى G، «السعر» اختيارى) ثم المنتج التام بعد عمود «اسم الصنف» الثانى |
| `stock_count_revised.xlsx` | اختيارى | الجرد المعدَّل إن صدر؛ يصبح رصيد أول المدة للشهر التالى بدل `stock_count.xlsx` |
| `valuation_issued.xlsx` | اختيارى | تقييم صادر للشهر من خارج النموذج؛ يُطابَق مع متوسط النموذج، ويُؤخذ منه سعر المنتج التام خارج الوصفات للشهر التالى |

ومرجع ثابت لكل الأشهر: `monthly/reference/recipes.xlsx` (الوصفات) و `monthly/reference/june_prices.xlsx`.

قبل الاحتساب: `python3 model/wac.py --check 2026-10` يسمّى كل ملف ناقص بالاسم ويخرج بخطأ.

## `month.json`

```json
{
  "month": "2026-10",
  "aliases_prev": {"الاسم بجرد الشهر": "اسمه بجرد آخر الشهر السابق"},
  "new_codes": {"123": {"item": "الصنف بالجرد", "confidence": "عالية", "basis": "سبب الربط"}},
  "unmatched": {"456": "لماذا لا يقابل هذا الكود أى صنف بالجرد"},
  "fg_aliases": {"اسم المنتج بالجرد": "اسمه بقواعد يوليو"},
  "corrections": [{"invoice": "…", "code": "…", "price": 30.0, "note": "تصحيح مؤكَّد من الإدارة"}],
  "outliers": [{"idx": 76, "code": "190", "note": "سعر شاذ يدخل كما سُجّل مع التنويه"}],
  "unresolved": {},
  "revised_aliases": {"الاسم بالجرد المعدَّل": "اسمه بجرد الشهر"},
  "issued_aliases": {"الاسم بالجرد المعدَّل": "اسمه بالتقييم الصادر"}
}
```

* الأكواد: يُستخدم ربط الأكواد من الأشهر السابقة تلقائيًا (الأقدم يغلب)؛ `new_codes` لما يظهر أول مرة فقط.
  كود جديد بلا ربط يوقف الاحتساب ويُسمّى الكود وسطره — لا يُحمَّل على صنف تخمينًا.
* `corrections` للتصحيحات المؤكَّدة فقط؛ المسجَّل بالتقرير يبقى للمطابقة مع الإجمالى المطبوع.
* `2026-07` شهر البداية (`"bootstrap": true`): أرصدة يوليو وأسعاره وربط أكواده وقواعد المنتج التام من
  `valuation_issued.xlsx` (= «تسعير جرد اخر شهر ٧ سنة ٢٠٢٦.xlsx»).

## وصفات الخامة الواحدة (تأكيد الإدارة 26/10/2026)

المعيار = خلطة التصنيع بمتوسط آخر الشهر. من `2026-10` يُسعَّر المنتج التام التالى بوصفته بدل آخر سعر صادر
(`MATERIAL_RULES` فى `model/wac.py`):

| المنتج التام بالجرد | الوصفة |
|---|---|
| مفروم ابو هاشم 350 | 0.32 كجم مجمع اللحوم الهندى + تعبئة 6.25 |
| كبده اسكندراني 370 | 0.34 كجم كبده + تعبئة 6.25 |

أغسطس وسبتمبر صدرا بالسعرين 84.61 و 64.10 فيبقيان كما صدرا. بالوصفة كانا: أغسطس 87.22 و 62.26
(أثر القيمة −77.34)، سبتمبر 89.53 و 63.58 (+585.08).

## المخرجات (تُولَّد، لا تُعدَّل يدويًا)

`python3 model/wac.py 2026-10` يكتب فى مجلد الشهر:
`wac.json` (متوسط كل صنف وسعر كجم الوصفات وسعر المنتج التام والقيم) و `REPORT.md` (الملخص وما يحتاج متابعة)،
و `stock_count_priced.xlsx` إن كان بالجرد عمود «السعر»: نسخة من الجرد لا يتغير فيها غير خانات السعر.

ثم `python3 model/monthly_standard.py 2026-10` يكتب `standard.json`: المعيار الشهرى = كل وصفة بمتوسط الشهر
(سعر كجم العجينة + الهانك للسجق، ووصفات المفروم والكبدة).

## الأشهر الحالية

ملفات `2026-07` و `2026-08` و `2026-09` نسخ من ملفات المستودع الأصلية (الأصول باقية فى مكانها كما هى):

| المجلد | الملف | الأصل |
|---|---|---|
| reference | recipes.xlsx | ABOHASHEM_تسعير_المنتجات_بمتوسط_التكلفة_يونيه2026.xlsx |
| reference | june_prices.xlsx | تسعير جرد اخر شهر ٦ سنة ٢٠٢٦.xlsx |
| 2026-07 | valuation_issued.xlsx | تسعير جرد اخر شهر ٧ سنة ٢٠٢٦.xlsx |
| 2026-08 | purchases.pdf | تقرير المشتريات شهر ٨ سنة ٢٠٢٦.pdf |
| 2026-08 | stock_count.xlsx | جرد شهر ٨ سنة ٢٠٢٦.xlsx |
| 2026-08 | stock_count_revised.xlsx | جر د شهر 8.xlsx |
| 2026-08 | valuation_issued.xlsx | تسعير جرد اخر شهر ٨ سنة ٢٠٢٦-2.xlsx |
| 2026-09 | purchases.pdf | مشتريات شهر سبتمبر سنة 2026.pdf |
| 2026-09 | stock_count.xlsx | جرد شهر 9.xlsx |

`month.json` لأغسطس وسبتمبر مولَّد من ثوابت `wac_august_2026.py` و `wac_september_2026.py` نفسها، والفحص
`model/tests/test_wac_engine.py` يثبت أن النموذج يعيد أسعار الشهرين الحالية نفسها صنفًا صنفًا.
